## 命名规范

文件命名格式：`NNN_<短描述英文>/`

- `NNN`：3 位数字编号（001, 002, ...）
- `<短描述>`：英文短语，下划线分隔，全小写

每个事件目录下建议包含：
- `README.md`（必需）：完整复盘文档
- `screenshots/`（可选）：相关截图
- `fix/`（可选）：修复相关的补丁或脚本

```markdown

- 截图
- 复现步骤

## 排查过程

- ...

## 根本原因
- 技术原理
- 为什么发生

## 修复方案

## 经验教训

- 类似问题的快速定位步骤
```
