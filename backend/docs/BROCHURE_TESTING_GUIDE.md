# 招生简章功能测试指南

## 测试目标
验证三个招生简章页面（开放大学、中职教育、成人高考）都能正确过滤和显示纯数字命名的图片。

## 测试环境准备

### 1. MinIO 目录结构
确保 MinIO 中存在以下目录结构：
```
zhpt-bucket/
  └── brochure/
      ├── open/          # 开放大学招生简章
      ├── vocational/    # 中职招生简章
      └── adult/         # 成人高考招生简章
```

### 2. 测试数据准备
在每个目录中上传测试图片：

#### 有效图片（应该显示）
- `1.jpg`
- `2.png`
- `3.jpg`
- `10.jpg`

#### 无效图片（应该被过滤）
- `street1.png`
- `street2.png`
- `cover.jpg`
- `test.png`

## 测试步骤

#### 1.1 测试开放大学

- 按排序号升序排列

#### 1.2 测试中职教育

**预期结果**: 同上

#### 1.3 测试成人高考

#### 3.1 空目录测试
1. 清空某个目录（如 adult）
2. 访问对应页面
3. **预期结果**: 显示"暂无招生简章"

#### 3.2 只有无效文件测试
1. 在目录中只放置无效文件（如 street1.png, cover.jpg）
2. 访问对应页面
3. **预期结果**: 显示"暂无招生简章"（因为所有文件都被过滤）

1. 上传文件：1.jpg, 2.jpg, 10.jpg, 100.jpg
2. 访问页面

1. 上传不同格式：1.jpg, 2.png, 3.gif, 4.jpeg

3. **预期结果**: 所有格式都能正常显示

### 测试 4: 上传接口测试

#### 4.1 正常上传
```bash
curl -X POST http://localhost:3050/brochure/upload/adult \
  -F "file=@test.jpg" \
  -F "sort=1"
```

**预期结果**: 
- 上传成功
- 文件被重命名为 `1.jpg`

#### 4.2 无效排序号测试
```bash
# 测试负数
curl -X POST http://localhost:3050/brochure/upload/adult \
  -F "file=@test.jpg" \
  -F "sort=-1"

# 测试零
curl -X POST http://localhost:3050/brochure/upload/adult \
  -F "file=@test.jpg" \
  -F "sort=0"
```

**预期结果**: 
- 返回错误："排序号必须是正整数"

#### 4.3 覆盖已存在文件
```bash
# 第一次上传
curl -X POST http://localhost:3050/brochure/upload/adult \
  -F "file=@test1.jpg" \
  -F "sort=1"

# 第二次上传相同排序号
curl -X POST http://localhost:3050/brochure/upload/adult \
  -F "file=@test2.jpg" \
  -F "sort=1"
```

**预期结果**: 
- 第二次上传成功
- 旧文件被覆盖

## 常见问题排查

### 问题 1: 图片不显示
**排查步骤**:
1. 检查 MinIO 中文件是否存在
2. 检查文件名是否为纯数字格式
3. 检查后端日志是否有错误
4. 检查前端控制台是否有错误

### 问题 2: 某些图片被过滤
**原因**: 文件名不是纯数字格式
**解决**: 在 MinIO 中重命名文件为纯数字格式（如 1.jpg）

### 问题 3: 排序不正确
**排查步骤**:
1. 检查文件名是否为纯数字
2. 检查后端是否按 sort 字段排序
3. 检查是否有重复的排序号

### 问题 4: 上传失败
**排查步骤**:
1. 检查 MinIO 连接是否正常
2. 检查排序号是否为正整数
3. 检查文件格式是否支持
4. 检查后端日志错误信息
