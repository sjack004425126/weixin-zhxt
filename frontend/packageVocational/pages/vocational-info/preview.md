# 学生信息页面 (vocational-info)

## 页面功能
- 展示学生基本信息
- 展示学籍信息
- 展示家庭信息
- 展示毕业学校信息

## 页面结构

### 1. 页面头部
- 页面标题：学生信息
- 状态标识：个人档案

### 2. 基本信息卡片
- 姓名
- 学号
- 性别
- 民族
- 身份证号
- 联系电话

### 3. 学籍信息卡片
- 入学年度
- 班级ID
- 专业ID
- 学籍状态
- 学生来源
- 招生对象

### 4. 家庭信息卡片
- 家庭地址
- 户口性质
- 居住地类型
- 监护人姓名
- 监护人关系
- 监护人电话

### 5. 毕业学校卡片
- 毕业学校名称
- 所属省份
- 所属地市
- 所属区县

## 设计特点

### 视觉设计
- 采用卡片式布局，信息分类清晰
- 每个卡片有不同颜色的状态指示器
- 使用网格布局展示信息，响应式设计
- 统一的图标和色彩体系

### 交互设计
- 下拉刷新功能
- 加载状态提示
- 错误重试机制
- 平滑的动画效果

### 数据处理
- 自动格式化显示数据
- 状态码转换为可读文本
- 空数据处理
- 错误状态处理

## 技术实现

### 组件使用
- Vant Weapp UI组件库
- 自定义top-message组件

### 数据获取
- 调用后端API：`/vocational_info/get_student_info`
- 使用tokenGet方法进行认证请求

### 状态管理
- 加载状态管理
- 错误状态处理
- 数据缓存机制

## 页面路由
```
pages/vocational-info/vocational-info
```

## 依赖接口
- GET `/vocational_info/get_student_info` - 获取学生信息
